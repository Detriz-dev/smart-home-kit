# Learning goals

- **Product specification** → PRD, user stories, acceptance criteria, story mapping, MoSCoW prioritization
- **Domain modelling** → Domain-Driven Design
- **Design system** → Figma, design tokens, Storybook, npm packaging
- **Product documentation** → Diátaxis
- **Continuous development** → Git, GitHub Actions (CI/CD), conventional commits, semantic versioning
- **AI-assisted development** → context files and conventions, skills, MCP in the workflow (Figma, Claude Code), prompting, reviewing and testing AI-generated code
- **Backend & API design** → FastAPI (Python), REST, WebSocket, OpenAPI, time-series storage
- **Frontend development** → HTML, CSS, React, TypeScript, data visualization
- **Electronics & hardware** → Raspberry Pi, I2C/GPIO sensors, sensor physics
- **3D design & printing** → snap-in module enclosures
- **AI engineering** → LLM APIs, tool calling, building an MCP server, generative UI, structured output, evals
