Add the kit to a React app and render your first component in three steps: install the packages, load the styles and fonts, and check that your own CSS doesn't override the kit.

## What you need

- **React 19** (`react` and `react-dom`). The kit's components use your app's React: they don't bring their own.
- **A bundler that understands ES modules and CSS imports**, like Vite or Next.js. The packages are ES modules only.
- **TypeScript** is optional. The types are included, so there's nothing extra to install.

## 1. Install the packages

The kit comes as two packages:

| Package                 | What's in it                                                         |
| ----------------------- | -------------------------------------------------------------------- |
| `@detriz-sh-kit/ui`     | The React components and their styles.                               |
| `@detriz-sh-kit/tokens` | The design tokens: the CSS variables the components are styled with. |

Install both. The kit's fonts come with `ui`, so there's nothing else to install:

## 2. Load the styles and fonts

Import the tokens, the components' styles and the fonts **once**, at the root of your app. Load the tokens first:

```tsx
import "@detriz-sh-kit/tokens/tokens.css";
import "@detriz-sh-kit/ui/styles.css";
import "@detriz-sh-kit/ui/fonts.css";
```

Where the root is depends on your setup:

| Setup                  | File             |
| ---------------------- | ---------------- |
| Vite                   | `src/main.tsx`   |
| Next.js (App Router)   | `app/layout.tsx` |
| Next.js (Pages Router) | `pages/_app.tsx` |

Without the first two, the components render without any styling. Without `fonts.css`, the text falls back to the system font. If your app already loads Space Grotesk and Space Mono its own way, skip `fonts.css`. See [Typography](/docs/ui-components/foundations/typography) for the fonts and text styles.

## 3. Check your own CSS

The kit's styles are inside a CSS cascade layer called `detriz`. Styles **outside** a layer always win over styles inside one, so global styles in your app, like a reset for every `button` or `ol`, can change the kit's components.

If your app has global styles, put them in a layer that comes before `detriz`:

```css
@layer reset, detriz;

@layer reset {
  /* your global styles */
}
```

If your app has no global styles, you can skip this step. See [Design tokens](/docs/ui-components/foundations/design-tokens#your-own-css-and-the-kit) for more.

## All together

The root of a Vite app, with everything in place:

```tsx title="src/main.tsx" {5-7}
import { StrictMode } from "react";
import { createRoot } from "react-dom/client";

// The kit's tokens, then its components' styles and fonts
import "@detriz-sh-kit/tokens/tokens.css";
import "@detriz-sh-kit/ui/styles.css";
import "@detriz-sh-kit/ui/fonts.css";

import { App } from "./App";

createRoot(document.getElementById("root")!).render(
  <StrictMode>
    <App />
  </StrictMode>,
);
```

## Check that it works

Render one component:

```tsx title="src/App.tsx"
import { SensorReading } from "@detriz-sh-kit/ui";

export function App() {
  return (
    <div style={{ maxWidth: 200 }}>
      <SensorReading metric="temperature" value={22.4} unit="celsius" />
    </div>
  );
}
```

:::note[Next.js App Router]
The kit's components run in the browser, so they can't be rendered in a Server Component. Put `"use client";` at the top of each file that renders them.
:::

You should see this:

```jsx live
<div style={{ maxWidth: 200 }}>
  <SensorReading metric="temperature" value={22.4} unit="celsius" />
</div>
```

If yours looks different:

| You see                                          | Likely cause                                           | Fix                                               |
| ------------------------------------------------ | ------------------------------------------------------ | ------------------------------------------------- |
| Plain text, no card                              | The styles aren't loaded.                              | Step 2: import `ui/styles.css`.                   |
| A card, but wrong colors or no spacing           | The tokens aren't loaded, or load after the styles.    | Step 2: import `tokens/tokens.css` first.         |
| The right layout, but a different font           | The fonts aren't loaded.                               | Step 2: import `ui/fonts.css`.                    |
| Extra indents, margins or bullets                | Your global CSS overrides the kit.                     | Step 3.                                           |
| A React error about hooks or two copies of React | React isn't version 19, or two versions are installed. | Install React 19 and check there's only one copy. |
