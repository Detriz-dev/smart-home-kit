# Icons

The kit has a small, fixed set of icons, shown with the `Icon` component. The components use them for Metrics, places and states. You can use them in your own screens too, so your icons match the kit's.

```jsx live
<Icon name="thermostat" />
```

## Import

```tsx
import { Icon } from "@detriz-sh-kit/ui";
```

The component needs the kit's styles. See [Design tokens](./design-tokens.mdx#loading-the-tokens).

## Basic usage

Pass the icon's name:

```tsx
import { Icon } from "@detriz-sh-kit/ui";

<Icon name="home" />;
```

## The icon set

The icons are [Material Symbols](https://fonts.google.com/icons), in the Rounded style at weight 400. Only the icons below exist in the kit: `name` accepts these names only, and TypeScript tells you if you pass anything else.

Every icon a component uses comes from a purpose map (see [Icons by purpose](#icons-by-purpose)), so the same meaning always gets the same icon.

| ---------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------- |

Illuminance uses `light_mode` (a sun), not a light bulb, because a bulb looks like a light you can switch, and the kit has no lights to switch.

## Icons by purpose

Don't pick icons by their base name: take them from the kit's purpose maps (all twelve are listed in [Which icon means what](#which-icon-means-what)), so every screen shows the same icon for the same thing.

```tsx
import { ASSET_TYPE_ICONS, Icon, METRIC_ICONS, SPACE_TYPE_ICONS } from "@detriz-sh-kit/ui";

<Icon name={METRIC_ICONS.smoke} />            // detector_smoke
<Icon name={SPACE_TYPE_ICONS.kitchen} />      // countertops
<Icon name={ASSET_TYPE_ICONS.appliance} />    // local_laundry_service
```

| Map                | Keys                                              | Used by                                      |
| ------------------ | ------------------------------------------------- | -------------------------------------------- |
| `METRIC_ICONS`     | Every [`Metric`](./shared-types.mdx#metric)       | [`SensorLabel`](../context/sensor-label.mdx) |
| `SPACE_TYPE_ICONS` | Every [`SpaceType`](./shared-types.mdx#spacetype) | [`SpaceLabel`](../context/space-label.mdx)   |
| `ASSET_TYPE_ICONS` | Every [`AssetType`](./shared-types.mdx#assettype) | No component yet                             |

```jsx live
<StackLayout>
  {Object.entries(ASSET_TYPE_ICONS).map(([assetType, name]) => (
    <span
      key={assetType}
      style={{
        display: "flex",
        alignItems: "center",
        gap: "var(--shk-space-2)",
      }}
    >
      <Icon name={name} />
      <code>{assetType}</code>
    </span>
  ))}
</StackLayout>
```

In Figma, each map is a component set on the Icon page, named after it (`MetricIcon`, `StateIcon`, `DeviceKindIcon`, `AlertLevelIcon`…). Pick the value and the size.

## Sizes

Use the `size` prop. The default is `md`.

| `size` | Size | Use it next to                          |
| ------ | ---- | --------------------------------------- |
| `xs`   | 16px | Small text (caption, 12px)              |
| `sm`   | 20px | 14px text                               |
| `md`   | 24px | 16px text. Default.                     |
| `lg`   | 32px | Large numbers, like a `lg` ReadingValue |

The icons are drawn on a 24px grid, so 20, 24 and 32px look sharpest. 16px is for small text, where 20px is too big.

```jsx live
<div
  style={{ display: "flex", alignItems: "center", gap: "var(--shk-space-4)" }}
>
  <Icon name="thermostat" size="xs" />
  <Icon name="thermostat" size="sm" />
  <Icon name="thermostat" size="md" />
  <Icon name="thermostat" size="lg" />
</div>
```

## Color

An icon takes the **text color** around it, so it always matches the text next to it. To change its color, change the text color of its parent:

```jsx live
<div style={{ display: "flex", gap: "var(--shk-space-4)" }}>
  <span style={{ color: "var(--shk-color-text-primary)" }}>
    <Icon name="error" />
  </span>
  <span style={{ color: "var(--shk-color-text-secondary)" }}>
    <Icon name="error" />
  </span>
  <span style={{ color: "var(--shk-status-danger-fg)" }}>
    <Icon name="error" />
  </span>
</div>
```

## Screen readers

Every icon is either **decorative** or **meaningful**:

- **Decorative**, when text next to it already says the same thing, like the thermostat next to "Temperature". Leave `label` out: screen readers skip the icon.
- **Meaningful**, when the icon is the only thing that says it, like a disconnected icon in place of a value. Pass a `label`: screen readers read it.

```jsx live
<StackLayout gap="sm">
  {/* Decorative: the text says the same thing */}
  <span
    style={{ display: "flex", alignItems: "center", gap: "var(--shk-space-1)" }}
  >
    <Icon name="thermostat" size="sm" />
    Temperature
  </span>
  {/* Meaningful: the icon is all there is */}
  <Icon name="link_off" label="Disconnected" />
</StackLayout>
```

Don't use an icon on its own as a button: there's no icon button in the kit yet. Use a [`Button`](../controls/button.mdx) with text.

## Props

| Prop    | Type                           | Default | Description                                                                                                 |
| ------- | ------------------------------ | ------- | ----------------------------------------------------------------------------------------------------------- |
| `name`  | `IconName`                     | –       | **Required.** Which icon to show. Only the names in the icon set work.                                      |
| `size`  | `"xs" \| "sm" \| "md" \| "lg"` | `"md"`  | 16, 20, 24 or 32px.                                                                                         |
| `label` | `string`                       | none    | What the icon means, read by screen readers, like "Disconnected". Leave it out when the icon is decorative. |

The types `IconProps`, `IconName` and `IconSize` are exported too:

```tsx
import type { IconName, IconProps, IconSize } from "@detriz-sh-kit/ui";
```

## Icons in a row

An icon never gets squashed in a row: it keeps its size, and the text next to it shrinks instead. That's why long names in `SensorLabel` and `LocationPath` end with `…` while their icons stay whole.

## Missing an icon?

The set is fixed, so every screen uses icons that have been checked together. If you need an icon that isn't in the set, ask for it to be added to the kit rather than mixing in icons from somewhere else.
