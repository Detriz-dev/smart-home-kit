The kit uses two fonts and 16 text styles. The components pick their text style themselves. Use the same styles in your own text, so your screens match the kit.

## The fonts

| Font              | Used for                                 | Weights the kit uses |
| ----------------- | ---------------------------------------- | -------------------- |
| **Space Grotesk** | Everything: headings, body text, numbers | 400, 500, 600, 700   |
| **Space Mono**    | Code                                     | 400                  |

## Loading the fonts

The tokens only **name** the fonts. The font files come with `@detriz-sh-kit/ui`: import `fonts.css` once, at the root of your app, next to the kit's styles:

```tsx
import "@detriz-sh-kit/tokens/tokens.css";
import "@detriz-sh-kit/ui/styles.css";
import "@detriz-sh-kit/ui/fonts.css";
```

It loads every weight the kit uses. The browser only downloads a weight when some text uses it, so this doesn't slow your app down. Without it, the text falls back to the system font.

### Loading the fonts your own way

`fonts.css` is optional. If your app already loads the fonts, for example from a CDN, skip it and load Space Grotesk (400, 500, 600 and 700) and Space Mono (400) yourself. Load each weight you need: a weight you don't load is faked by the browser and looks blurry.

## Text styles

Each style is five tokens: `--shk-typography-<style>-font-family`, `-font-size`, `-font-weight`, `-line-height` and `-letter-spacing`.

| Style        | Size | Weight | Line height | Letter spacing | Used by                                                      |
| ------------ | ---- | ------ | ----------- | -------------- | ------------------------------------------------------------ |
| `display`    | 64px | 700    | 70px        | -1.28px        | Big hero text                                                |
| `h1`         | 40px | 700    | 44px        | -0.8px         | Your page's main heading                                     |
| `h2`         | 32px | 600    | 40px        | -0.64px        | `ContentSection` level 2                                     |
| `h3`         | 24px | 600    | 30px        | 0              | `ContentSection` level 3                                     |
| `h4`         | 20px | 600    | 25px        | 0              | `ContentSection` level 4, `ModuleCard` and `SpaceCard` names |
| `body-lg`    | 18px | 400    | 27px        | 0              | `SensorLabel` `lg`                                           |
| `body`       | 16px | 400    | 24px        | 0              | Running text, `SensorLabel` `md`                             |
| `body-sm`    | 14px | 400    | 21px        | 0              | `SensorLabel` `sm`, `InlineMessage` text                     |
| `label`      | 14px | 500    | 18px        | 0              | `Button`, `Switch`, `InlineMessage` title                    |
| `caption`    | 12px | 400    | 18px        | 0              | `LocationPath`, `SensorLabel` `xs`, the Status components    |
| `overline`   | 12px | 500    | 18px        | 0.48px         | Small labels above a heading                                 |
| `readout-lg` | 48px | 500    | 53px        | -0.96px        | `ReadingValue` `lg`                                          |
| `readout`    | 32px | 500    | 35px        | -0.64px        | `ReadingValue` `md`, `UnitLabel` `lg`                        |
| `readout-sm` | 20px | 500    | 22px        | -0.4px         | `ReadingValue` `sm`, `UnitLabel` `md`                        |
| `readout-xs` | 14px | 500    | 15px        | -0.28px        | `ReadingValue` `xs`, `UnitLabel` `sm` and `xs`               |
| `code`       | 14px | 400    | 21px        | 0              | Code (Space Mono)                                            |

The `readout` styles are for numbers: they have tight line heights, so a value and its Unit sit close together.

```jsx live
function TextStyles() {
  const styles = [
    "display",
    "h1",
    "h2",
    "h3",
    "h4",
    "body-lg",
    "body",
    "body-sm",
    "label",
    "caption",
    "overline",
    "readout-lg",
    "readout",
    "readout-sm",
    "readout-xs",
    "code",
  ];
  const text = (name) => ({
    fontFamily: `var(--shk-typography-${name}-font-family)`,
    fontSize: `var(--shk-typography-${name}-font-size)`,
    fontWeight: `var(--shk-typography-${name}-font-weight)`,
    lineHeight: `var(--shk-typography-${name}-line-height)`,
    letterSpacing: `var(--shk-typography-${name}-letter-spacing)`,
    color: "var(--shk-color-text-primary)",
  });

  return (
    <StackLayout gap="sm">
      {styles.map((name) => (
        <div
          key={name}
          style={{
            display: "flex",
            alignItems: "baseline",
            gap: "var(--shk-space-4)",
          }}
        >
          <code style={{ minInlineSize: "7rem" }}>{name}</code>
          <span style={text(name)}>
            {name.startsWith("readout") ? "22.4" : "Bedroom"}
          </span>
        </div>
      ))}
    </StackLayout>
  );
}
```

## In Figma

Each style is a **text style** in the kit's [Figma library](https://www.figma.com/community/file/1700179982740576850/detriz-smart-home-kit), with the same name: `h2` in Figma is `--shk-typography-h2-*` in code. The text styles are bound to the `typography` variables, so they always match the tokens.

Space Grotesk in Figma is a variable font. `h2`, `h3` and `h4` use weight 600, which Figma sets on the weight axis, so the style picker may still call the font **Bold**.

## Using a text style in your CSS

Set all five tokens, so the size, weight and spacing stay in step:

```css
.my-page-title {
  font-family: var(--shk-typography-h1-font-family);
  font-size: var(--shk-typography-h1-font-size);
  font-weight: var(--shk-typography-h1-font-weight);
  line-height: var(--shk-typography-h1-line-height);
  letter-spacing: var(--shk-typography-h1-letter-spacing);
}
```

Match the text style to the HTML element: `h2` for an `<h2>`, and so on. That way what people see matches what screen readers announce. [`ContentSection`](../layout/content-section.mdx) does this for you.

## Numbers

Values in the Readings components use **tabular figures**: every digit is the same width, so a layout doesn't jump when 19.9 becomes 20.0. Use the same in your own lists of numbers:

```css
.my-table td {
  font-variant-numeric: tabular-nums;
}
```
