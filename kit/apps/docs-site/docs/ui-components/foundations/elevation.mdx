Cards are **raised**: they sit a little above the page, with a soft shadow and a thin outline. Everything else (messages, banners, statuses) stays flat, in the page.

## The layers

| Layer      | Fill                              | Outline                                               | Shadow                   | Used for                                                                 |
| ---------- | --------------------------------- | ----------------------------------------------------- | ------------------------ | ------------------------------------------------------------------------ |
| **Page**   | `--shk-surface-page` (gray 50)    | None                                                  | None                     | The screen behind everything, and the header strip of a card             |
| **Card**   | `--shk-surface-default` (white)   | `--shk-border-width-thin` `--shk-color-border-subtle` | `--shk-elevation-raised` | `Card`, `DeviceCard`, `SpaceCard`                                        |
| **Flat**   | `--shk-surface-default` or a tint | `--shk-border-width-thin`                             | None                     | `SensorReading`, `InlineMessage`, `AlertBanner`, `EmptyState`            |
| **Sunken** | `--shk-surface-sunken` (gray 100) | None                                                  | None                     | An area set into a card, like a code sample. Not used by the components. |

```jsx live
<div
  style={{
    background: "var(--shk-surface-page)",
    padding: "var(--shk-space-6)",
    borderRadius: "var(--shk-radius-16)",
  }}
>
  <Card
    title="Climate Module"
    headerEnd={<DeviceConnectionStatus status="connected" />}
  >
    <SensorReading metric="temperature" value={22.4} unit="celsius" size="md" />
  </Card>
</div>
```

## The shadow

| Token                    | Value                                |
| ------------------------ | ------------------------------------ |
| `--shk-elevation-raised` | `0 1px 4px`, gray 950 at 12% opacity |

It is soft on purpose: it lifts the card just enough to separate it from the page. Keep the 1px outline next to it. In Windows High Contrast mode the browser removes shadows but keeps borders, so the outline is what keeps the card's edge.

## Building your own surfaces

The easiest way is to use [`Card`](../layout/card.mdx): it has the header strip, the white body and the shadow. If you need your own surface, use the same tokens:

```css title="src/styles/space-summary.css"
.space-summary {
  background: var(--shk-surface-default);
  border: var(--shk-border-width-thin) solid var(--shk-color-border-subtle);
  border-radius: var(--shk-radius-16);
  box-shadow: var(--shk-elevation-raised);
  padding: calc(var(--shk-space-4) - var(--shk-border-width-thin));
}
```

Give the shadow room: don't put cards in a parent with `overflow: hidden` right at their edge, or the shadow is cut off.

## In Figma

Build a card as a frame with:

- **Fill:** `surface/default` (and `surface/page` for a header strip)
- **Stroke:** `color-border/subtle`, **Inside**, weight `border-width/thin`
- **Effect:** the effect style `elevation/raised`
- **Corner radius:** `radius/16`

## Floating layers: not in the kit yet

Some components will float above the page: a toast, a dialog, a menu. They will need a stronger shadow and **layer order** (z-index) tokens, so a dialog always covers a toast. They will be added with the first floating component.
